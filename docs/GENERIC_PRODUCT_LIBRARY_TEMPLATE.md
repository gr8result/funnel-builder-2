# Generic Product Library Template

The standard Product Library template defines selection structure only. Suppliers, brands, ranges, products, colours, finishes, sizes, images, prices and supplier URLs are organisation-scoped catalogue data.

The reusable template seeds:

- Category hierarchy for Exterior, Interior, Kitchen, Bathroom & Ensuite, Laundry, Bedrooms, Living Areas, Garage, Outdoor Areas and Pool.
- Product-family definitions for Stone Benchtops, Metal Roofing, Bricks and Internal Doors as the first acceptance families.
- Required attributes and allowed variant types.
- Stable quotation item code links.
- Generic category images from platform-owned media.
- Demonstration Product placeholders that builders can delete or replace.

No supplier is platform structure. Supplier-specific names in the approved CSV are retained as source evidence and converted into generic product-family requirements.
