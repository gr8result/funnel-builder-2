# Product Library Source Of Truth

The master source for quotation-derived items that belong in the selections template is:

`data/product-library/PRODUCTS-LIBRARY.csv`

This CSV was manually curated and approved by the user. It defines which quotation-derived items are allowed to become Product Library and Selections requirements.

Codex must not reclassify, restore, or add unrelated estimating items that the user removed from this file.

The Quotation Builder remains unchanged. This source file does not alter quote rows, formulas, rates, layout, calculations, or existing Quotation Builder behaviour.

The Product Library and Inclusions & Selections system must be built from this file.

Supplier-specific data is organisation-specific. Supplier names, brands, ranges, product images, prices, specification links, and supplier URLs must not be hard-coded into the generic Product Library template.
