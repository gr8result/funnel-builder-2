# Product Library Quotation Links

Every approved selection item keeps or receives a stable quotation item code. Actual products link to that code through `linkedQuotationItemCode` or import field `linked_quote_item_code`.

Generated codes are a preview until approved. They are unique, source-row traceable and remain reserved after use. The parser preserves any genuine existing item code and does not alter Quotation Builder rows, formulas or calculations.

Completed selection rows can carry quotation item code, selected product code, area, room, quantity, unit, variant, price, allowance, variation, supplier and notes for a future Quotation Builder import.
