# Inclusions & Selections

The visible milestone is a category-first selections experience backed by the shared Product Library.

Current responsibilities:

- choose an area such as Exterior, Kitchen or Interior
- choose one product family such as Bricks, Stone Benchtops or Internal Doors
- load exact products for that family only
- show an explicit empty state when the organisation has not imported products
- keep Product Library Admin tools separate from the normal catalogue

Non-goals:

- no Quotation Builder rebuild
- no quote formula changes
- no procurement, approvals, document or estimate export work

The Product Library owns supplier/product import and organisation scoping. Inclusions & Selections consumes exact product-family queries.
