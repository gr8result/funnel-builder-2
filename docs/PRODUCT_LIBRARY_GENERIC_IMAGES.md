# Product Library Generic Images

Category tiles use generic platform media, not supplier product imagery. The current mapping lives in `GENERIC_CATEGORY_IMAGES` and is also used by the Product Library visual browser.

The image contract is:

- Category image represents the family visually.
- Commercial supplier product images are not used as standard defaults unless authorised.
- Builder-specific product images live on organisation product records.
- Products with missing or unverified images can be flagged for review.
