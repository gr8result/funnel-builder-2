# Product Library Category Hierarchy

The reusable hierarchy is defined in `PRODUCT_LIBRARY_CATEGORY_HIERARCHY`.

- Roofing Materials maps to `Exterior -> Roofing`.
- Entry Doors maps to `Exterior -> Entry Doors`.
- Entry Door Furniture maps to `Exterior -> Entry Door Hardware`.
- Garage Doors maps to `Exterior / Garage -> Garage Doors`.
- Face Brickwork maps to `Exterior -> Bricks`.
- External Cladding maps to `Exterior -> Cladding`.
- Fix Out maps to `Interior -> Fix Out -> Internal Doors, Door Hardware, Skirting, Architraves, Robes`.
- Cabinetry maps to Kitchen, Bathroom, Ensuite and Laundry cabinetry/benchtop families.
- Appliances maps to `Kitchen -> Ovens, Cooktops, Rangehoods, Dishwashers, Microwaves`.
- Plumbing Fittings & Tapware maps to Bathroom, Ensuite, Kitchen and Laundry plumbing families.
- Floorcoverings maps to Bedrooms, Living Areas and Interior flooring families.
