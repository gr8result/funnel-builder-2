# Product Library Selections Visual Workflow

The selections workflow has three levels.

## Level 1: Selection Item List

Room View and Category View show the same ProjectRequirements. Each row shows status, a selected-product thumbnail/placeholder, selection item name, selected product name, tier/category badge, allowance/selected price and variation state.

## Level 2: Product Picker

Clicking a row opens the shared picker. Desktop uses left filters and a product grid. Mobile stacks filters and cards. Product cards show image placeholder, brand, name, model/spec line, supplier, tier, allowance, client price, variation, availability and Select.

## Level 3: Product Details

Clicking a product image or View Details opens a larger detail view with media, gallery placeholders, product identity, supplier/SKU, price/allowance/variation and variant selection. Supplier website links open only the stored URL in a new tab with `rel="noopener noreferrer"`.
