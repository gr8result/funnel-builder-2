# Supplier Links And Images

Supplier links are exact stored URLs only. The app must not build URLs from product names, brands, SKUs or search results. Product and supplier links open in a new tab with `target="_blank"` and `rel="noopener noreferrer"`. Missing links are displayed as missing, not guessed.

Images are data-driven. Supported fields include thumbnail image, primary image, gallery images, colour swatch, finish image, technical drawing, image alt text, source URL, source type and verification status. Missing images use placeholders. Supplier imagery must retain source and verification metadata where required.
